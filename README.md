Open WebUI Assistant
------------------------------------------

We made this as a way to connect Open WebUI to chrome and other web-based apps/locations.

Main Site: https://www.graytechnical.com/open-webui-assistant/

Chrome Web Store: https://chromewebstore.google.com/detail/open-webui-assistant/alojhgbfgnfdmclldiecnadgkpifbego


------------------------------------------

🎯 Two Different Menus, One Powerful Tool
When You Select Text:
✏️ Rewrite – Improve clarity, edits directly on page
✓ Fix Grammar – Instant corrections in place
🔍 Check Grammar – Detailed explanations in side panel
📈 Expand – Add 25% more detail
📉 Shorten – Condense while keeping key points
📄 Summarize – Concise summaries in side panel
💬 Chat – Discuss selected text with full context
When Nothing is Selected:
📖 Explain This Page – Full page summary and analysis
✅ Perfect For Privacy-Conscious Organizations
Unlike cloud AI tools that send your data to external servers,
Open WebUI Assistant connects only to YOUR local AI instance:

✓ Works with your local Open WebUI deployment
✓ No data sent to third-party services
✓ All processing happens on your infrastructure
✓ Complete control over your AI interactions

Ideal for: Educational institutions, healthcare, legal, enterprise,
and any organization requiring local AI processing.

🚀 Works Everywhere
✅ Google Workspace – Seamlessly injected into Docs, Sheets, Slides native menus ✅ Gmail & Outlook – Direct on-page text editing
✅ Any Website – Universal right-click menu ✅ All Text Fields – Works in forms, editors, content areas

💡 Smart Features
In-Place Editing – Most actions replace text directly on the page. No copy-paste needed.

Intelligent Side Panel – Beautiful interface with:

Full markdown rendering with syntax highlighting
Copy as plain text or formatted HTML
Text-to-speech for reading aloud
Contextual chat remembering page content and previous outputs
Model switching on the fly
Advanced Text Capture – Works even in complex web apps like Google Docs using intelligent clipboard techniques

🔐 Your Data, Your Rules
Connects only to YOUR Open WebUI instance (local or private server)
Zero third-party services
Zero data collection
Zero tracking
Credentials encrypted locally in Chrome
📋 Requirements
A running Open WebUI instance (local or network)
Valid Open WebUI credentials
At least one AI model configured
